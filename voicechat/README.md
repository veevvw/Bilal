# تشغيل الأغاني داخل اتصال تيليجرام

يدير كود Go البحث وقائمة الانتظار والصلاحيات. تشغّل الخدمة المحلية `service.py` الحساب المساعد بواسطة Kurigram وPyTgCalls، وتبث صوت الأغنية في اتصال المجموعة عبر FFmpeg. يبدأ البوت هذه الخدمة تلقائيًا عند تفعيلها؛ لا يلزم تشغيلها بصورة منفصلة، ولا يلزم فتح `/player` للاستماع داخل الاتصال.

## الإعداد

1. استخدم Linux أو Docker مع تشغيل Docker Engine.
2. ضع `VOICE_CHAT_ENABLED=true` و`STRING_SESSION` في `.env`. يجب أن تكون الجلسة لحساب مستخدم بصيغة Pyrogram/Kurigram، وليست توكن بوت. تم نقل الجلسة الموجودة في `gg` إلى `.env` لهذا المشروع.
3. أضف البوت والحساب المساعد إلى المجموعة. اجعل البوت مشرفًا، واسمح للحساب المساعد بالتحدث في الاتصال؛ رفعه مشرفًا بصلاحية إدارة المحادثات الصوتية يجنّبه الكتم الافتراضي.
4. افتح الاتصال الصوتي في المجموعة يدويًا. الخدمة لا تنشئ اتصالًا جديدًا تلقائيًا.
5. شغّل من جذر المشروع:

   ```sh
   docker compose up --build -d
   ```

   يُظهر سجل بدء التشغيل اسم الحساب المساعد ومعرّفه، دون عرض الجلسة. لعرض السجل:

   ```sh
   docker compose logs -f tg-web
   ```

6. أرسل `/play اسم الأغنية` داخل المجموعة. تعمل أيضًا `/pause` و`/resume` و`/skip` و`/seek` و`/stop` وقوائم التشغيل والتكرار. عند نهاية مدة الأغنية ينتقل مدير قائمة الانتظار إلى التالية. تستمر الموسيقى إذا لم يكن هناك مستمعون في مشغل الويب.

## التشغيل خارج Docker

ثبّت FFmpeg وPython 3.10 أو أحدث، ثم:

```sh
python3 -m venv .venv
.venv/bin/pip install -r voicechat/requirements.txt
```

اضبط `VOICE_CHAT_PYTHON=.venv/bin/python` في `.env` وشغّل البوت من جذر المشروع. لا تضبط هذا المتغير عند استخدام Docker؛ الصورة تحدّد مسار Python المناسب تلقائيًا.

إذا كانت الجلسة ملغاة، يتوقف بدء الخدمة برسالة واضحة، دون طلب رقم هاتف أو رمز دخول تفاعلي. إذا خرج المساعد من المجموعة أو لم يجد اتصالًا مفتوحًا، يعرض البوت إرشادًا بالعربية أو الإنجليزية بدل الإبلاغ عن تشغيل وهمي.

تعطيل `VOICE_CHAT_ENABLED` يعيد التشغيل إلى مشغل الويب. تظل الغرف الخاصة تستخدم مشغل الويب؛ بث الحساب المساعد مخصّص لاتصالات المجموعات.

## عندما يرفض YouTube التنزيل

إذا طلب YouTube تسجيل الدخول، ضع ملف Cookies حديثًا بصيغة Netscape في `secrets/youtube.cookies.txt` واضبط `YTDLP_COOKIES_FILE=/app/secrets/youtube.cookies.txt` داخل `.env`. يُركّب مجلد `secrets` للقراءة فقط داخل الحاوية، ويستخدم البرنامج نسخة مؤقتة خاصة دون تعديل الملف الأصلي أو حذفه. عند تغيير الإعداد أعد إنشاء الحاوية: `docker compose up -d`. استبدال محتوى ملف Cookies في نفس المسار لا يحتاج إعادة بناء الصورة.

## التحقق

```sh
go test ./internal/voicechat ./internal/webapp
python3 -m unittest discover -s voicechat -v
```

تستخدم الاختبارات خدمة وحسابًا وهميين ولا تسجّل الدخول إلى تيليجرام. الاختبار الحقيقي يحتاج مجموعة مفتوحًا فيها اتصال صوتي وحسابًا مساعدًا مسموحًا له بالتحدث.
